# IGRAI® — лендинг

Одностраничный сайт с 3D-анимацией ноутбука по скроллу.

## Как запустить

Двойной клик по **`start.bat`** — откроется `http://localhost:8080/`.
Остановить сервер: `Ctrl+C` в чёрном окне.

> Просто открыть `index.html` двойным кликом нельзя: браузер запрещает загружать
> `.glb`-модель с `file://`. Поэтому нужен локальный сервер — его и поднимает `start.bat`
> (нужен установленный Python или Node.js, обычно Python уже есть).

## Структура

```
index.html                вся разметка
assets/
  style.css               стили (палитра, секции, адаптив)
  app.js                  3D-сцена и скролл-таймлайн
  fonts.css, fonts/       Unbounded + Manrope (локально, латиница + кириллица)
  tunnel.jpg              фон первого экрана
  shop.jpg                фото витрины («О нас» и B2B)
  vendor/three/           three.js r169 + GLTFLoader (локально, без CDN)
asus_rog_animated.glb     модель ноутбука (клип «Lid_Open»)
start.bat                 локальный сервер
```

## Загрузка и вес модели

Первый экран не ждёт 3D: заголовок, текст и кнопки появляются сразу, модель
догружается в фоне. Пока она едет, сверху идёт тонкая полоска прогресса,
а под первым экраном — «Загружаем 3D-модель · N%». Никакого занавеса на весь
экран нет: страница читается и листается с первой секунды.

Дорожка прокрутки под анимацию (`--stage-h`, 640vh) разворачивается только
когда модель готова **и** посетитель ещё на первом экране. Если он успел уйти
вниз, страница не прыгает: каталог показывается обычной секцией, а анимация
включается, когда он вернётся наверх. Тот же путь работает, если 3D не
запустилось совсем — каталог всё равно на месте.

Модель сжата: **12,4 МБ → 2,4 МБ**. Что сделано — убраны неиспользуемые
атрибуты вершин (касательные и второй набор UV, ни один материал их не
использовал), текстуры переведены в WebP, геометрия сжата `EXT_meshopt_compression`
с квантованием. Оригинал лежит рядом как `asus_rog_animated.source.glb` —
на сервер не заливается. Если не нужен в репозитории, удалите его или добавьте
в `.gitignore`.

Пережать заново после правок модели:

```bash
npm i -g @gltf-transform/cli
gltf-transform prune  in.glb s1.glb --keep-attributes false --keep-indices false
gltf-transform dedup  s1.glb s2.glb
gltf-transform webp   s2.glb s3.glb --slots "!normalTexture"
gltf-transform meshopt s3.glb asus_rog_animated.glb --level high
```

Распаковывает это в браузере `assets/vendor/three/examples/jsm/libs/meshopt_decoder.module.js`
(20 КБ) — он подключается в `app.js` через `setMeshoptDecoder`. Без него
сжатая модель не откроется.

## Анимация ноутбука

Весь таймлайн — в `assets/app.js`, объект `T` (доли прокрутки секции `.stage`, 0 → 1):

| ключ            | что происходит                                       |
|-----------------|------------------------------------------------------|
| `openA/openB`   | крышка открывается (клип `Lid_Open`, 0 = закрыт)      |
| `camA/camB`     | облёт: от ближнего левого угла петли к виду в лоб     |
| `heroA/heroB`   | уходит текст первого экрана                           |
| `uiA/uiB`       | обои ROG сменяются нашим тёмным интерфейсом           |
| `cardA/cardB`   | на экране проявляются 4 карточки                      |
| `blowA/blowB`   | корпус разрастается за границы экрана                 |
| `fadeA/fadeB`   | корпус растворяется                                   |
| `morfA/morfB`   | карточки отрываются от экрана и встают в сетку        |
| `chrmA/chrmB`   | исчезает «рамка окна» вокруг карточек                 |
| `headA/headB`   | появляется заголовок «Каталог техники»                |

Ракурс камеры — объект `CAM` (`az0/az1` — азимут, `el0/el1` — высота, `d0/d1` — дистанция).
Длина прокрутки сцены — переменная `--stage-h` в `assets/style.css` (по умолчанию `640vh`).

## Публикация на GitHub и GitHub Pages

Заливать нужно **содержимое этой папки**, а не саму папку — чтобы `index.html`
оказался в корне репозитория, иначе GitHub Pages его не найдёт.

### Вариант 1 — через сайт GitHub (без установки чего-либо)

1. Откройте репозиторий → **Add file → Upload files**.
2. Перетащите в окно браузера: `index.html`, `README.md`, `start.bat`,
   `asus_rog_animated.glb` и **папку `assets` целиком**.
   Папки перетаскивать можно — структура сохранится.
3. Дождитесь, пока догрузится модель (13 МБ), впишите комментарий
   и нажмите **Commit changes**.

### Вариант 2 — через GitHub Desktop

1. Поставьте GitHub Desktop, войдите в аккаунт.
2. **File → Clone repository** → выберите `igrai_2_landing`.
3. Скопируйте в склонированную папку всё содержимое этой папки.
4. Слева появятся изменения → впишите сообщение → **Commit to main** →
   **Push origin**.

### Включить GitHub Pages

Repository → **Settings → Pages** → Source: **Deploy from a branch** →
Branch: `main`, папка `/ (root)` → **Save**.

Через 1–2 минуты сайт будет доступен по адресу
`https://polina-kad.github.io/igrai_2_landing/`

После этого локальный сервер и `start.bat` больше не нужны — все пути
в проекте относительные, поэтому сайт работает и в подпапке.
